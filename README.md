## 🚀 Cara Menggunakan

1. **Buka Landing Page**: `index.html`
   - Jelajahi semua fitur
   - Scroll ke berbagai section
   - Klik tombol Daftar
   - Baca blog dan testimoni

2. **Akses Admin Panel**: `admin.html`
   - Lihat dashboard
   - Kelola data siswa
   - Kelola data guru
   - Manage paket
   - Kelola booking

3. **Customize Data**:
   - Edit `data.js` untuk mengubah database
   - Update kontak di `index.html`
   - Modifikasi styling di `style.css`

## 💡 Customization Tips

1. **Ubah Nama Bimbel**: Edit logo di navbar dan footer
2. **Ubah Kontak**: Update info di `index.html` section kontak
3. **Tambah Guru**: Update `data.js` array `guruData`
4. **Tambah Testimoni**: Update `data.js` array `testimonialData`
5. **Tambah Blog**: Update `data.js` array `blogData`
6. **Ubah Warna**: Edit `:root` variables di `style.css`
7. **Ubah Harga Paket**: Update di `index.html` section paket
